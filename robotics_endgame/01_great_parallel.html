The Great Parallel

Mirroring the three-step evolutionary leaps of AI. What text models achieved digitally is now happening in physical robotics.

The Evolution Path
Digital / Language

1. Next Token Prediction

Self-supervised learning across internet-scale data to predict the next word.

  • Scale: Pre-trained on 1T - 15T tokens of raw text.
  • Core Concept: By learning to compress text, the model inherently learns world models, grammar, and facts.
  • Milestones: GPT-1/2/3, Chinchilla, LLaMA base models.
  • Limitation: Produces rambling text; not aligned to follow specific user instructions.

2. Instruction Tuning

Supervised fine-tuning (SFT) to teach the model how to respond to commands.

  • Scale: Requires 10k - 100k high-quality Q&A pairs.
  • Core Concept: Transforms a document-completer into a helpful assistant. Formats the unstructured knowledge into conversational utility.
  • Milestones: InstructGPT, Flan-T5, Alpaca.
  • Limitation: Can still confidently hallucinate or generate harmful content if asked.

3. RLHF

Reinforcement Learning from Human Feedback for final alignment and nuance.

  • Mechanism: Uses a secondary "Reward Model" trained on human preferences to penalize bad answers and reward good ones.
  • Core Concept: Optimization for Helpfulness, Honesty, and Harmlessness (HHH). Allows the model to generalize beyond basic SFT.
  • Milestones: ChatGPT, Claude, GPT-4.
  • Result: Mass adoption of AI interfaces.
Physical / Action

1. Next World State Prediction

Pre-training on massive video and physics data to predict what happens next visually.

  • Scale: Millions of hours of egocentric video and YouTube.
  • Core Concept: Vision-Language-Action (VLA) models learn physics, object permanence, and affordances just by watching videos.
  • Milestones: RT-1, RT-2, OpenVLA.
  • Limitation: Understands the world, but lacks the specific motor control to act precisely in it.

2. Action Fine-Tuning

Behavioral cloning from human teleoperation data to teach specific physical tasks.

  • Scale: Requires 10k - 100k teleoperated trajectories (e.g., folding shirts, making coffee).
  • Core Concept: Maps the general world understanding directly to robot joint torques and motor actions (Action Chunking).
  • Milestones: ALOHA, Mobile ALOHA, ACT.
  • Limitation: Fails when encountering out-of-distribution physical states (e.g., dropping an object).

3. Robot RL

Reinforcement learning in Simulation and the Real World to achieve superhuman dexterity.

  • Mechanism: Agent explores and optimizes a reward function in GPU-accelerated simulators (Isaac Gym), then transfers to reality.
  • Core Concept: Self-correction, dynamic recovery, and emergent behaviors that humans cannot explicitly teleoperate.
  • Milestones: Eureka, DayDreamer, Sim-to-Real quadruped locomotion.
  • Result: Autonomous, general-purpose robots.
