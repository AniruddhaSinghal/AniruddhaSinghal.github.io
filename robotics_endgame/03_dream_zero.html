Dream Zero

Predictive World Models: The ability to simulate the future, calculate rewards, and visualize actions before moving a single physical motor.

t = 0.0s

1. State Encoding

The robot observes the current physical scene via cameras and proprioception.

z_t = Encoder(Observation)
t + 0.5s

2. Action Proposal

The latent policy suggests a possible movement trajectory into the future.

a_t ~ Policy(z_t)
t + 1.0s

3. State Prediction

The World Model accurately predicts what the scene will look like after moving.

z_{t+1} = WorldModel(z_t, a_t)
t + 1.5s

4. Reward Evaluation

If the predicted state avoids collision and reaches the target, the physical movement is executed.

R = Evaluate(z_{t+n}) > Threshold
