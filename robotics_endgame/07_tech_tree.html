The Robotics Tech Tree

Mapping the civilizational milestones required to finish the game and unlock Physical Artificial General Intelligence.

Internet Models
Internet Scale VLM
Unlocked (2023)
Requires: 10T+ Tokens, Vision Encoders
Models capable of understanding images, text, and basic visual physics. The foundation for all higher-order reasoning.
Sim-to-Real
Sim-to-Real Locomotion
Unlocked (2024)
Requires: GPU Physics Engines, RL
The ability for quadruped and bipedal robots to learn walking dynamics in simulation and immediately apply them in reality without falling over.
Action Chunking
Teleop Action Chunking
Unlocked (2024)
Requires: 10k+ Teleop Trajectories
Behavioral cloning that smooths out jerky movements, allowing robots to perform specific tasks (like cooking) but only in controlled environments.
General W.A.M.
World Action Models
In Progress
Requires: 1M+ Ego-Video Hours, 50Hz Control
Natively multimodal models that skip the text bottleneck, outputting motor torques directly from visual inputs with superhuman latency.
Physical Turing Test
Physical Turing Test
Locked (Endgame)
Requires: Emergent Tactile Generalization
The point where watching a robot interact with the world (folding laundry, assembling a chair) is indistinguishable in fluidity and adaptability from a human.
Physical Auto-Research
Physical Auto-Research
Singularity Node
Requires: Physical API + High Intelligence
Robots designing better robot hardware, manufacturing it in factories run by robots, and training the software. The physical intelligence explosion.
Physical API
The Physical API
Locked (Endgame)
Requires: 10M+ Real-World Deployments
The physical world becomes programmable. You can write software to "clean the kitchen" and the robot executes it flawlessly, just like calling a software function.
